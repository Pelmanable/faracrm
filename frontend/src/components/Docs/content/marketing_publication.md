Раздел «Маркетинг» публикует ролики по расписанию: в группу или канал Telegram (постами через бота, сторис и постами от имени аккаунта), в сторис сообщества ВКонтакте, на YouTube, Rutube и в Instagram. Ролик загружается один раз, а выходить может сколько угодно раз — вручную или по правилу повтора.

## Как устроено

| Раздел              | Что в нём                                                                                                                                                                                       |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ролики**          | Видео, название и подпись. Хранится один раз, повторы ссылаются на него.                                                                                                                        |
| **Каналы**          | Куда публиковать: группа Telegram (через бота или от имени аккаунта), сообщество ВКонтакте, канал YouTube или Rutube, аккаунт Instagram. Настройка — в статье «Маркетинг: подключение каналов». |
| **Публикации**      | Что, куда, когда и в каком формате. Это же журнал: видно, что вышло, ссылку и текст ошибки.                                                                                                     |
| **Правила повтора** | «Раз в N часов / дней / недель — следующий ролик в эти каналы».                                                                                                                                 |

Раз в минуту планировщик (задача «Маркетинг: публикации по расписанию») создаёт публикации по правилам и отправляет все, у которых подошло время.

> [!warning] Если выключить эту задачу в «Планировщике», публикации перестанут выходить.

## Ролик

- **Видео** — файл до 50 МБ (ограничение бота Telegram).
- **Название** — заголовок видео на YouTube и Rutube.
- **Подпись** — через бота Telegram или MAX уходит отдельным сообщением перед видео; от имени аккаунта Telegram — подписью к видео или сторис; на YouTube и Rutube становится описанием; в Instagram — подписью к Reels. У сторис Instagram и ВКонтакте подписи нет.

Требования площадок к видео:

| Площадка         | Что важно                                                 |
| ---------------- | --------------------------------------------------------- |
| Telegram         | Любое видео до 50 МБ.                                     |
| Telegram сторис  | До 60 секунд, лучше вертикальное.                         |
| ВКонтакте сторис | Короткое вертикальное видео.                              |
| YouTube          | Вертикальное видео до 3 минут YouTube сам сделает Shorts. |
| Rutube           | Обычное видео; категория — «Разное».                      |
| Instagram Reels  | MP4 или MOV, H.264, от 3 секунд до 15 минут, лучше 9:16.  |
| Instagram сторис | От 3 до 60 секунд, лучше 9:16.                            |

## Формат публикации

| Формат     | Где работает                                                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Пост**   | Telegram (бот и аккаунт) — сообщение с видео; YouTube — видео (Shorts, если вертикальное до 3 минут); Rutube — видео; Instagram — Reels. |
| **Сторис** | Instagram, Telegram (аккаунт) и ВКонтакте (канал «Через коннектор» с коннектором VK).                                                    |

Если формат не подходит каналу (сторис через бота Telegram или MAX, на YouTube или Rutube; пост через коннектор VK), публикация получит ошибку «Этот формат публикации в канале такого типа не поддерживается».

## Разовая публикация

1. **Публикации → Создать.**
2. Выберите ролик, канал, формат и время («Когда»).
3. Сохраните. В назначенное время (с точностью до минуты) статус станет «Опубликована»; для YouTube, Rutube, Instagram и ВКонтакте в поле «Ссылка» появится адрес видео или истории.

## Правило повтора

1. **Правила повтора → Создать.**
2. Добавьте ролики, каналы и выберите формат.
3. Задайте «Каждые» и «Интервал» (часов, дней, недель) и «Следующий запуск» — время первой публикации.
4. Оставьте включённым «Активно».

При каждом запуске правило берёт ролик, идущий за «Последним роликом», и создаёт по публикации на каждый канал. После последнего ролика снова идёт первый. Ролики идут в порядке, в котором их завели в систему.

Если сервер был выключен, пропущенные запуски не догоняются: следующая публикация выйдет в ближайшее время по расписанию.

> [!tip] Сторис живут 24 часа. Чтобы одни и те же ролики показывались каждый день, поставьте правило «Каждые 1 день, формат Сторис».

## Статусы и ошибки

- **Запланирована** — ждёт своего времени.
- **Опубликована** — ушла; время и ссылка — в карточке.
- **Ошибка** — текст причины в поле «Ошибка».

Чтобы повторить публикацию с ошибкой, исправьте причину (например, подключите канал заново) и верните статус «Запланирована» — она уйдёт в ближайшую минуту.

## Где вышел ролик: статус по каналам

Одна публикация — это один ролик в одном канале. Поэтому, если ролик ушёл в несколько каналов (вручную или по правилу), у него столько же публикаций, и у каждой свой статус.

Все они видны в карточке ролика, в разделе **«Где выходил: статус по каналам»**: канал, формат, статус, когда вышел, ссылка и текст ошибки. Клик по строке открывает публикацию.

Повтор затрагивает только ту публикацию, которой вы вернули статус «Запланирована»: если ролик вышел в Telegram и на YouTube, а в Instagram упал, повторите только публикацию Instagram — в Telegram и на YouTube он второй раз не уйдёт.

> [!info] Правило повтора при каждом запуске создаёт **новые** публикации — так ролики и повторяются по кругу. История прошлых выходов остаётся в карточке ролика.

> [!info] Через бота Telegram подпись и видео — два сообщения. Если упало на видео, подпись уже в группе; при повторе она уйдёт ещё раз.

## Доступ

Раздел открывает роль «Маркетинг: пользователь». Client Secret каналов видит только администратор.

## Для администратора: обновление модуля

Если модуль «Маркетинг» был установлен до появления каналов YouTube и Instagram, один раз выполните в базе:

```sql
ALTER TABLE marketing_channel
  ALTER COLUMN connector_id DROP NOT NULL,
  ALTER COLUMN chat_id DROP NOT NULL;
UPDATE cron_job SET timeout = 1800
  WHERE name = 'Маркетинг: публикации по расписанию';
```

Новые поля добавляются сами при перезапуске сервера; SQL нужен только для этих двух изменений.

Флаг «Поддерживается в маркетинге» у коннектора ставится сам, когда в форме коннектора выбирают тип. Коннекторам, созданным раньше, его нужно поставить один раз — иначе их не будет в списке «Коннектор» у канала:

```sql
UPDATE chat_connector SET marketing = type IN ('telegram', 'max_bot', 'vk');
```

Если у вас были каналы типа «ВКонтакте», они теперь — «Через коннектор» с тем же коннектором VK:

```sql
UPDATE marketing_channel SET type = 'chat' WHERE type = 'vk';
```

Для каналов «Telegram (аккаунт)» на сервере нужны пакеты `telethon` и `hachoir`. В `requirements.txt` они закомментированы: раскомментируйте строки, выполните `pip install -r requirements.txt` (в Docker — пересоберите образ backend) и перезапустите сервер. Остальные каналы работают и без них.
