Канал — место, куда уходят публикации. Тип канала определяет площадку.

| Тип                    | Что публикует                                                                       | Как подключается                                     |
| ---------------------- | ----------------------------------------------------------------------------------- | ---------------------------------------------------- |
| **Через коннектор**    | Telegram и MAX — видео сообщением в группу или канал; ВКонтакте — сторис сообщества | Существующий коннектор чата: Telegram, MAX или VK    |
| **Telegram (аккаунт)** | Сторис и посты в группу или канал от имени аккаунта                                 | Кнопка «Войти в Telegram» (телефон и код)            |
| **YouTube**            | Видео и Shorts                                                                      | Кнопка «Подключить YouTube» (вход через Google)      |
| **Rutube**             | Видео                                                                               | Кнопка «Войти в Rutube» (логин и пароль)             |
| **Instagram**          | Reels и сторис                                                                      | Кнопка «Подключить Instagram» (вход через Instagram) |

## Через коннектор: Telegram, MAX, ВКонтакте

Канал типа «Через коннектор» публикует через уже настроенный коннектор чата (раздел «Коннекторы»). В поле «Коннектор» видны только коннекторы с флагом **«Поддерживается в маркетинге»** — это Telegram, MAX и VK. Флаг ставится сам, когда в форме коннектора выбирают его тип. Остальные коннекторы (Avito принимает только картинки, почта — для рассылок, телефония файлы не отправляет) в списке не показываются.

Что сделает публикация, решает тип выбранного коннектора:

| Коннектор    | Что указать в «Id группы или канала»   | Формат | Как уходит ролик                                           |
| ------------ | -------------------------------------- | ------ | ---------------------------------------------------------- |
| Бот Telegram | `-100…` или `@username`                | Пост   | Видео с плеером; подпись — отдельным сообщением перед ним. |
| Бот MAX      | Id чата, где состоит бот               | Пост   | Видео; подпись — отдельным сообщением перед ним.           |
| VK           | Не нужен — сообщество берётся из ключа | Сторис | Сторис сообщества (подробнее — ниже).                      |

## Telegram: группа или канал

1. Бот уже подключён коннектором Telegram (раздел «Коннекторы»).
2. Добавьте бота в группу. В канал — администратором с правом публиковать сообщения.
3. Узнайте id группы: откройте её в [web.telegram.org](https://web.telegram.org) — id в адресной строке после `#`, у групп и каналов он вида `-100…`.
4. **Каналы → Создать:** тип «Через коннектор», коннектор Telegram, id группы.

> [!warning] Сторис бот публиковать не может: Telegram разрешает ботам сторис только от имени бизнес-аккаунта, а не в группы и каналы. Для сторис заведите канал типа «Telegram (аккаунт)» — ниже.

## Telegram: сторис от имени аккаунта

Сторис в группу или канал публикует обычный аккаунт Telegram, а не бот. Этот же канал умеет и посты — видео сообщением от имени аккаунта.

Что нужно:

- аккаунт — **администратор** группы или канала с правом **«Публикация историй»**;
- у группы или канала **уровень бустов не ниже 1** — без него Telegram не даёт публиковать истории. Бусты дарят подписчики с Telegram Premium; чем выше уровень, тем больше сторис в день;
- на сервере установлены пакеты `telethon` и `hachoir`. В `requirements.txt` они закомментированы — раскомментируйте строки и выполните `pip install -r requirements.txt` (в Docker — пересоберите образ backend).

Один раз на [my.telegram.org](https://my.telegram.org):

1. Войдите номером телефона аккаунта.
2. **API development tools** → заполните название и короткое имя приложения (любые, например «FARA CRM»).
3. Скопируйте **api_id** и **api_hash**.

В CRM:

1. **Каналы → Создать:** тип «Telegram (аккаунт)», в «Id группы или канала» — `-100…` или `@username`, Client ID = api_id, Client Secret = api_hash → **Сохранить**.
2. Нажмите **«Войти в Telegram»** в верхней панели формы и введите телефон аккаунта.
3. Введите код — он придёт в приложение Telegram на этом аккаунте. Если включена двухфакторная защита, следом введите пароль. Пароль нигде не сохраняется.
4. Страница обновится, флажок «Подключён» включится.

Сторис живёт 24 часа и видна всем; подпись ролика становится подписью сторис. Видео — до 60 секунд, лучше вертикальное.

> [!warning] Вход даёт CRM полный доступ к аккаунту. Лучше завести для маркетинга отдельный аккаунт. Сессия видна в Telegram: **Настройки → Устройства → FARA CRM** — там её можно завершить; после этого войдите в канале заново.

## ВКонтакте: сторис сообщества

Сторис публикуются от имени сообщества через **коннектор VK** — тот же, что принимает сообщения сообщества в чаты (раздел «Коннекторы»). Через маркетинг коннектор VK сообщений не шлёт — только сторис.

1. В ключ доступа сообщества нужно право **«Истории»**: ВКонтакте → управление сообществом → **Работа с API → Ключи доступа**. Если в ключе коннектора этого права нет, создайте новый ключ с правами «Сообщения», «Управление сообществом» и «Истории» и вставьте его в коннектор VK вместо старого.
2. **Каналы → Создать:** тип «Через коннектор», коннектор — ваш коннектор VK → **Сохранить**. Id группы не нужен — сообщество берётся из ключа.
3. Публикации и правила для этого канала — с форматом **«Сторис»**.

Сторис видна в сообществе 24 часа; в поле «Ссылка» публикации появится адрес истории.

> [!info] Видео-посты и клипы ВКонтакте через API недоступны: видео загружает только метод `video.save` с ключом пользователя и правом `video`, а ВКонтакте выдаёт это право в исключительных случаях — по запросу на devsupport@corp.vk.com. Публикация с форматом «Пост» в канале ВКонтакте получит ошибку.

## YouTube

Один раз в [Google Cloud Console](https://console.cloud.google.com/):

1. Создайте проект и включите **YouTube Data API v3** (APIs & Services → Library).
2. **OAuth consent screen:** тип External, добавьте scope `youtube.upload`, затем переведите приложение в статус **In production**. В статусе Testing доступ истекает через 7 дней.
3. **Credentials → Create credentials → OAuth client ID**, тип **Web application**. В Authorized redirect URIs укажите `<адрес API>/marketing/youtube/callback`.
4. Скопируйте Client ID и Client Secret.

Адрес API — системный параметр `core.api_url`, например `https://crm.example.ru/api`. При локальной установке Google принимает только `http://localhost:…`, поэтому `127.0.0.1` заменяется на `localhost` автоматически.

В CRM:

1. **Каналы → Создать:** тип YouTube, Client ID, Client Secret → **Сохранить**.
2. Нажмите **«Подключить YouTube»** в верхней панели формы, войдите в Google-аккаунт владельца канала и разрешите доступ. Предупреждение «Приложение не проверено» для своего приложения можно пропустить через «Дополнительно».
3. После надписи «Канал подключён» в карточке включится флажок «Подключён».

Видео выходят открытыми (public): заголовок — название ролика, описание — подпись. Лимит — 100 загрузок в сутки на проект Google.

## Rutube

Нужен канал на Rutube и логин с паролем от него.

1. **Каналы → Создать:** тип «Rutube» → **Сохранить**.
2. Нажмите **«Войти в Rutube»** в верхней панели формы и введите логин (почту или телефон) и пароль. CRM получит токен и сохранит только его; пароль не сохраняется.
3. Страница обновится, флажок «Подключён» включится. Если смените пароль на Rutube — войдите в канале заново.

Видео выходят открытыми, в категории «Разное» (её можно сменить в Rutube Studio): заголовок — название ролика, описание — подпись. Сторис у Rutube нет — только формат «Пост».

> [!info] Rutube, как и Instagram, сам скачивает видео с вашего сервера по временной ссылке — адрес API должен открываться из интернета. Rutube качает и обрабатывает файл уже после публикации, а когда закончит — сообщает CRM, и ссылка закрывается. Если обработать видео не удалось, публикация сменит статус на «Ошибка».

> [!warning] Официальной документации у этого API Rutube нет: оно работает по адресам старого официального клиента Rutube. Если Rutube его поменяет, публикации получат ошибку — сообщите об этом разработчикам CRM.

## Instagram

Подходит только **профессиональный** аккаунт (Бизнес или Автор). Страница Facebook не нужна.

Один раз у Meta:

1. В приложении Instagram: **Настройки → Тип аккаунта и инструменты → Переключиться на профессиональный аккаунт**.
2. На [developers.facebook.com](https://developers.facebook.com/apps) создайте приложение (тип Business) и добавьте продукт **Instagram → API setup with Instagram login**.
3. **App roles → Roles → Instagram testers:** добавьте свой аккаунт, затем примите приглашение в Instagram (**Настройки → Приложения и сайты → Приглашения тестировщика**). Для своего аккаунта хватает режима разработки — проверка приложения в Meta не нужна.
4. **Business login settings → OAuth redirect URIs:** `<адрес API>/marketing/instagram/callback`.
5. Скопируйте **Instagram App ID** и **Instagram App Secret**.

В CRM:

1. **Каналы → Создать:** тип Instagram, Client ID = Instagram App ID, Client Secret = Instagram App Secret → **Сохранить**.
2. Нажмите **«Подключить Instagram»**, войдите в аккаунт и разрешите доступ.
3. Доступ действует 60 дней. При публикации, если до конца осталось меньше 30 дней, он сам продлевается ещё на 60. Если публикаций долго не было и доступ истёк — подключите канал заново.

> [!info] Instagram сам скачивает видео с вашего сервера по временной ссылке, которая работает только во время публикации. Адрес API должен открываться из интернета по https — с локальной установки опубликовать в Instagram нельзя.

Обработка видео в Instagram занимает до 5 минут, поэтому публикация может появиться через несколько минут после назначенного времени. Лимит — 100 публикаций через API в сутки.

> [!warning] Если сервер в России, Instagram с него обычно недоступен — укажите прокси (ниже). Учтите и закон: с 1 сентября 2025 года в РФ запрещено размещать рекламу на ресурсах Meta, и ролики с продвижением товаров или услуг могут под это попасть.

## Прокси

Поле **«Прокси»** в разделе «Подключение» — для YouTube, Rutube и Instagram, если сервер не видит площадку напрямую. Формат: `http://user:pass@host:port`. Прокси используется и при подключении, и при публикации. Для Telegram-аккаунта и ВКонтакте прокси не используется.
